# Mission: How Skills Work

## Why

Use skills daily and want to understand the architecture — how they're structured, loaded, discovered, and invoked. Knowing the system from the inside will make you a more effective user and eventually enable you to build your own.

## Success looks like

- Can explain the anatomy of a SKILL.md file from memory
- Can trace how a skill gets from disk to invocation
- Can navigate any skill's file structure without help
- Can modify an existing skill with confidence

## Constraints

- Lessons under 10 minutes each
- Brand new to the topic — start from zero
- Prefer real examples from this repo over abstract theory

## Out of scope

- Writing or publishing skills (future mission)
- Contributing to the opencode/agent tooling itself
- Skill distribution formats or marketplaces
